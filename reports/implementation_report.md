# 实现对照报告 — V3/V4 文档 vs 当前代码实现

以下报告将 V3.0 与 V4.0 文档的关键条目逐项比对到代码库，说明已实现、部分实现或未实现，并给出短期优先级建议。

## 概要
- 已实现（可运行原型）：挂机回收、基础战斗回合、背包/装备基础、招募基础（含圣晶）、事件触发与选项、导入 V5 数据脚本。
- 部分实现（需要完善或扩展）：招募保底/概率微调、装备掉落与词缀、角色技能/升级细节、事件多样性、副本节点复杂度。
- 未实现（高优先级待办）：多存档槽与导入/导出、战斗技能系统（主动/被动/状态）、建筑/基地系统、无限回廊、转生系统、GM 调试工具、移动 UI 完整适配。

## 逐项对照（选取目录式关键条目）

1. 玩家/角色等级系统
  - 文档：统一经验表、等级倍率、角色升级消耗等（V4 完整表）。
  - 实现：`js/v5data.js` 包含 `expTable`，`GameCore.expForLevel` 与 `addExp` 存在，但角色升级点数消耗与 UI 显示未完全接入（点数消耗仅为记录）。
  - 状态：部分实现。

2. 角色六维与星级
  - 文档：六维属性、星级倍率、职业模板。
  - 实现：`js/v5data.js` 和 `js/config.js` 含角色基础六维；代码在 `getEffectiveStats` 中使用 `muscle`/`cell` 等，但星级/星级倍率未在战斗生效。`
  - 状态：部分实现（星级影响缺失）。

3. 战斗系统
  - 文档：回合制、速度、技能（主动/被动）、状态（眩晕/感染/控制）、连击/反击等。
  - 实现：`GameCore.battleRound` 为极简模拟（按团队攻击与概率判定胜负），没有技能、速度排序或状态逻辑。
  - 状态：未完成（核心需重构）。

4. 装备系统
  - 文档：随机词条、套装、强化、分解与按稀有度掉落规则（14世界/难度表）。
  - 实现：基础装备数据存在，`generateDungeon`/`advanceDungeon` 当前仅随机选装备并简单按 difficulty 触发圣晶掉落；未实现词缀、分解、套装。`equipmentDrops` 表已在 `v5data.js`。`
  - 状态：部分实现（掉落概率表存在，未完全接入）。

5. 副本与事件
  - 文档：多节点路线、事件/精英/Boss/宝箱/商店节点、评价系统。
  - 实现：`generateDungeon` 可生成节点并随机事件或战斗；事件选择 (`handleEventChoice`) 实现基础奖励；节点类型与复杂路线、Boss 特殊保底未实现。
  - 状态：部分实现。

6. 招募与货币
  - 文档：多种货币、招募消耗、保底、碎片转化与十连折扣。
  - 实现：`holy_crystal`、`recruitCosts`（single/ten）、十连折扣与碎片转化已实现，pity 逻辑存在，但十连保底与进度显示可以加强。`
  - 状态：已实现（需要 UI 完善）。

7. 存档与导出
  - 文档：多存档槽、导入/导出 JSON、自动保存策略。
  - 实现：`save`/`load` 使用 `localStorage` 单槽，已实现备份脚本但多槽导出/导入未实现。`
  - 状态：未完成（进行中）。

8. 长期玩法（无限回廊、转生、基地）
  - 文档：回廊层数、转生点、建筑影响挂机与收益。
  - 实现：无明显实现。`
  - 状态：未实现。

9. UI / 移动体验
  - 文档：移动优先、底部 Tab、多货币头部显示、触控优化。
  - 实现：基础移动友好 HTML/CSS 已有，重要交互可用，但视觉与交互需要优化。`
  - 状态：部分实现。

10. 调试/G M 工具
  - 文档：GM 控制台/开发快捷命令。
  - 实现：无。
  - 状态：未实现。
