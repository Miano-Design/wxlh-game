# 无限轮回

以主神空间为基地、以恐怖世界为副本的单机放置 Roguelite 手游（纯静态网页，手机竖屏）。

**在线试玩**：https://miano-design.github.io/wxlh-game/

## 玩法

- 🌀 **轮回副本**：14 个恐怖世界 × 3 难度 × 12 关，随机路线 + 随机事件 + Boss 机制战
- 👥 **角色收集**：60 名轮回者，六维属性 / 升星 / 技能 / 六大血统 / 基因锁五阶
- ⚔️ **回合战斗**：速度出手、暴击闪避、10 种异常状态、阵营克制、Boss 70%/30% 阶段
- 🎒 **装备养成**：6 种品质、随机词条、6 部位（主角与招募角色都是 6 槽）、世界套装 2/4/6 件、职业套装、+20 强化
- 🔒 **装备管理**：锁定保护（锁定后不参与分解、不被一键换装）、一键最优装备、与当前穿戴红绿对比、批量分解
- 🧰 **道具背包**：消耗品 / 经验模块 / 强化材料 / 装备箱分类，宝箱与经验模块支持 1 / 10 / 全部批量使用，点任意道具看「说明 / 在哪用 / 去哪弄」
- 🎒 **背包页签**：背包是一级页签（不再藏在弹窗里），卡片上直接给「开 / 喂 / 服 N」快捷键
- 🗓 **今日卡**：首页顶部四行告诉你"今天该做什么"（挂机 / 每日任务 / 免费招募 / 限时悬赏），「一键收取」把所有已达成未领取的奖励一次收完
- 🎯 **三张招募池**：**花三种货币、出三种结构** —— 普通池（◈点数）攒碎片、高级池（✦圣洁晶石）补图鉴且优先给未拥有、限定池（◆异界结晶）定向出当期 UP（50 抽必出），保底按池分开记账
- ⚡ **编队与自动**：3 组编队预设一键切换、自动战斗开关（直接出结果）
- ⏳ **放置挂机**：在线/离线收益、基地五大建筑加成、防改时间
- 🧭 **挂机分工**：4 条产线（闭关修炼 / 灵材采集 / 外围探索 / 主神守卫）各派 1 名领队，产出看领队的**对应六维**（闭关=精神 / 采集=肌肉 / 探索=神经 / 守卫=免疫，封顶 +150%），上阵主力不能派 —— 板凳角色的用处
- 🐾 **伴生体 + 五行克制**：第二条养成线。孵化兽魂石得伴生体，给全队加属性；金木水火土相克，带对属性进本全队伤害 +15%、带反 -8%（在战斗伤害公式里结算）
- 🔥 **限时悬赏**：4 条带截止时间的目标，**按你的当前进度动态生成**（推进当前世界 / 等级 / 强化次数 / 回廊 / 图鉴 / 伴生体 / 渡劫），到点作废，结束后可开新一期
- 🌌 **境界渡劫**：主角每 10 级一境，渡劫成功全属性永久 +5%；失败只扣材料、**等级不掉**，可反复挑战
- 🔁 **推图连续性**：战斗结算页直接给「↻ 再来一次 / › 下一关」，最后一关自动顺延到下一难度、下一世界
- ♾ **无限回廊**：无限爬塔终局玩法 + 回廊商店；「回廊印记」每 10 层 +1.5% 回廊内属性（上限 +45%），越爬越强
- ♻ **转生系统**：四支永久天赋树（40 个节点全部实装，文案与效果同源），轮回重生
- 📜 **任务系统**：主线 16 步引导 + 每日 6 条 + 周常 5 条（周一重置，全清奖励）+ 20 项成就（战斗/养成/收集/挑战）
- 🔊 **手感与保护**：手机返回键接管（先关面板再退页面）、副本进度实时落盘（刷新/切后台可续打）、合成音效
- 🎛 **五条全局交互规则**：热区 ≥44px、同按钮 300ms 防连点、货币收支 ±数值跳动、成功/失败回执（失败抖动）、大额消费二次确认（可在设置里关）
- ❓ **玩法指南与货币图鉴**：设置页 / 首页进入，逐章讲清副本、站位、装备、货币、血统、回廊；货币点一下就看用途与来源
- 📕 **角色图鉴**：收集进度 + 里程碑奖励
- 🧹 **便捷功能**：可选关卡与次数的扫荡（每日 60 次）、自动分解白装 / 绿装

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 测试

```bash
node scripts/test_game.js   # 逻辑测试
node scripts/test_ui.js     # 界面冒烟测试
```

`test_game.js`（244 项）内含回归用例：免费招募 / SSR 券计入主线、十连按折扣价整笔结算、
强化失败不吞材料、七日登录七天一循环、背包满不扣钱、自动分解、图鉴奖励、
**40 个转生天赋节点逐级生效**、世界套装 4/6 件可达、装备锁定、一键最优装备不重复分配、
编队预设、周常跨周重置、成就领取、成长曲线量级、高阶物品来源、商店按进度上架、回廊曲线与印记、
副本进度落盘、战斗引擎消费天赋字段（减伤 / 开场能量）、**血清上限与血统限制**、
**三池货币与出率结构 / 普通池 200 抽不出 SSR / 高级池保底优先给未拥有 / 限定池 50 抽必出当期 UP**、
**挂机分工加成与材料产出**、**限时悬赏期限与过期作废**、**渡劫门槛与失败不掉级** 等。

`test_ui.js`（63 项）用 DOM 桩把全部面板与一级页面渲染一遍，捕捉模板、空引用与 `undefined` 漏字。

## 存档

存档保存在浏览器 localStorage（saveVersion 5，旧档自动迁移到 6 装备槽并补齐新字段），支持 3 个手动存档槽 + JSON 导出/导入。
